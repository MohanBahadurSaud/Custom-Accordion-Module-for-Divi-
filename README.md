# Custom Accordion Module for Divi 5

A custom accordion module built for [Divi 5](https://www.elegantthemes.com/documentation/developers/divi-5/) with a clean, responsive design and Visual Builder support.  
Create expandable accordion items with custom titles, icons, content, and images.

## Features

- 📋 Create multiple accordion items
- 🎨 Customize accordion titles, icons, and content
- 🖼️ Add a custom image to each accordion item
- 📁 Select images directly from the WordPress Media Library
- 🔄 Display the active item's image in the image panel
- 🖼️ Use a default image when no custom image is selected
- 📱 Responsive design for desktop and mobile
- ⚡ Built for the Divi 5 Visual Builder
- 🎯 Custom frontend JavaScript and CSS
